# Rajasthan Digital Help — V2

Included:
- Responsive jobs website
- Demo admin panel for adding recruitment entries
- Official Notification + Apply Online fields
- SEO meta description and canonical
- robots.txt
- sitemap.xml
- Backend API contract for automatic source fetching, AI extraction, link verification and publishing

Important:
- Replace `https://example.com` with the real domain.
- Demo admin panel is client-side only; it is NOT secure authentication.
- Automatic fetching requires a deployed backend, database, scheduler, and approved/accessible official RSS/API sources.
- Use only verified official recruitment URLs before publishing.
